# Mangalam Demo Website

A frontend-only React + Vite concept website for a first client presentation.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite (normally http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

1. Create a GitHub repository and push this folder.
2. In Vercel, import the GitHub repository.
3. Vercel should detect Vite automatically.
4. Deploy.
5. Share the generated `vercel.app` URL with the client as a demo.

## Important

This is a concept/demo, not the final production website. Product images, logo, phone, email, address, social links, actual product data, enquiry handling and any backend/database functionality should be replaced/connected after the client confirms the requirements.

The contact/enquiry form is intentionally demo-only and does not send real data.
